The `social.colibri.beta.permissionMessaging` permission set grants `read`, `create`, `update` and `delete` on `social.colibri.beta.message` and `social.colibri.beta.reaction` in voice channel spaces, so members can post and react in a voice channel's chat. Sessions approved under the previous set need to approve the new scope.
